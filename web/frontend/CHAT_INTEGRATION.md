## Как использовать

### Для сотрудников
1. Выберите "Профиль сотрудника" на главной странице
2. Перейдите в раздел "Чат"
3. Задавайте вопросы о развитии карьеры, навыках и т.д.

### Для HR
1. Выберите "HR Личный кабинет" на главной странице
2. В левом меню выберите "HR Чат"
3. Задавайте вопросы о поиске кандидатов, анализе резюме и т.д.

## API Endpoints

- `POST /chat/user` - Чат для сотрудников
- `POST /chat/hr` - Чат для HR
- `GET /health` - Проверка состояния API
- `GET /agents` - Информация о доступных агентах

## Тестирование

Для тестирования API можно использовать функцию `testAPI()` в консоли браузера:

```javascript
// В консоли браузера
testAPI()
```

## Требования

### Локальный запуск
- Backend должен быть запущен на `http://localhost:8000`
- Frontend должен быть запущен на `http://localhost:3000` (Vite dev server)

### Docker запуск
- Все сервисы запускаются через `docker-compose up`
- Backend доступен на `http://localhost:8000`
- Frontend доступен на `http://localhost:3000`

## Возможные проблемы

1. **CORS ошибки** - убедитесь, что backend настроен для работы с frontend
2. **API недоступен** - проверьте, что backend запущен на правильном порту
3. **Ошибки сети** - проверьте подключение к интернету и доступность API

## Запуск приложения

### Через Docker Compose (рекомендуется)
```bash
# Запуск всех сервисов
docker-compose up --build

# Запуск в фоновом режиме
docker-compose up -d --build

# Остановка
docker-compose down
```

### Локальный запуск
```bash
# Backend (в корневой папке проекта)
uv run python main.py

# Frontend (в папке web/frontend)
npm install
npm run dev
```
