# 🎤 Руководство по голосовому вводу

## Обзор

В приложение добавлена поддержка голосового ввода для обоих чатов (User и HR). Пользователи могут записывать голосовые сообщения, которые автоматически транскрибируются и обрабатываются соответствующими агентами.

## 🚀 Возможности

### ✅ Что реализовано:
- **Запись аудио** - встроенный рекордер с поддержкой паузы/возобновления
- **Предварительный просмотр** - возможность прослушать записанное аудио перед отправкой
- **Автоматическая транскрипция** - конвертация речи в текст на backend
- **Интеграция с агентами** - транскрибированный текст автоматически отправляется в соответствующий агент
- **Поддержка форматов** - mp3, mp4, mpeg, mpga, m4a, wav, webm
- **Индикаторы состояния** - показ процесса записи, транскрипции и обработки

### 🔧 Технические детали:
- **Frontend**: Web Audio API для записи, React компоненты
- **Backend**: FastAPI эндпоинты для транскрипции
- **Форматы**: WebM (запись), поддержка множества форматов (воспроизведение)
- **API**: RESTful эндпоинты `/audio/transcriptions` и `/v1/audio/transcriptions`

## 📡 API Эндпоинты

### POST `/audio/transcriptions`
Транскрипция аудио файла в текст

**Параметры:**
- `file` (form-data) - аудио файл
- `agent_type` (form-data) - тип агента: "hr" или "user"
- `conversation_id` (form-data, опционально) - ID сессии

**Ответ:**
```json
{
  "text": "Транскрибированный текст",
  "agent_type": "user",
  "conversation_id": "conv_123",
  "processing_time": 1.23,
  "chat_response": {
    "response": "Ответ агента",
    "agent_type": "user",
    "conversation_id": "conv_123",
    "processing_time": 2.45
  }
}
```

### POST `/v1/audio/transcriptions`
Алиас для совместимости с OpenAI API

## 🎯 Использование

### В User Chat:
1. Нажмите кнопку "Записать" рядом с полем ввода
2. Разрешите доступ к микрофону
3. Говорите в микрофон
4. Нажмите "Стоп" для завершения записи
5. Прослушайте запись (опционально)
6. Запись автоматически отправится на транскрипцию и обработку

### В HR Chat:
Аналогично User Chat, но сообщения обрабатываются HR агентом.

## 🔧 Компоненты

Основной компонент для записи аудио:
- Запись с паузой/возобновлением
- Предварительный просмотр
- Таймер записи
- Обработка ошибок

### ChatPage & HRChatPage
Обновлены для поддержки голосового ввода:
- Интеграция с AudioRecorder
- Обработка транскрипции
- Индикаторы состояния

## 🛠️ Настройка

### Backend
Эндпоинты уже настроены в `main.py`. Для реальной транскрипции нужно интегрировать с OpenAI Whisper API:

```python
# В main.py, строка 320, заменить заглушку на:
import openai
client = openai.OpenAI(api_key="your-api-key")
with open(temp_file_path, "rb") as audio_file:
    transcript = client.audio.transcriptions.create(
        model="whisper-1",
        file=audio_file
    )
transcribed_text = transcript.text
```

### Frontend
Компоненты готовы к использованию. Убедитесь, что:
- Браузер поддерживает Web Audio API
- Пользователь разрешил доступ к микрофону
- HTTPS соединение (требуется для доступа к микрофону)

## 🚨 Ограничения

### Текущие:
- **Заглушка транскрипции** - используется тестовый текст вместо реальной транскрипции
- **Нет сохранения аудио** - записи не сохраняются на сервере
- **Ограниченные форматы** - только WebM для записи

### Планируемые улучшения:
- Интеграция с OpenAI Whisper
- Сохранение аудио файлов
- Поддержка больше форматов
- Улучшенная обработка ошибок
- Настройки качества записи

## 🔒 Безопасность

- Аудио файлы временно сохраняются и автоматически удаляются
- Валидация типов файлов
- Ограничение размера файлов (можно добавить)
- CORS настроен для всех источников (в продакшене ограничить)
